Repository for HIT140 Assessment 2 (Darwin Group 45). This project contains datasets, Python analysis scripts, processed data, and outputs analyzing FIFA World Cup 2026 player and team performance metrics.

## Project overview
- Purpose: exploratory data analysis and basic statistical comparisons across player roles and performance metrics (playing time, defensive actions, fouls, goalkeeping performance).
- Each team member contributed a focused analysis contained in a named subfolder.

## Repository structure
- **Dinuka-Playing-Time-by-Player-Position/**: playing time analysis, outputs
- **Sehan-Fouls-Analysis/**: fouls analysis, outputs
- **Bala-Goalkeeping-Performance/**: goalkeeping performance analysis, outputs
- **Prabodha-Defensive-Performance/**: defensive performance analysis, outputs

## Data and outputs
- Each subfolder contains a **code/** directory with a Python script. 
- **data/raw** contains the original datasets, and **data/processed** contains cleaned and processed datasets used in the analyses.
- Outputs (CSVs and PNGs) are written to the **outputs/** directory inside each analysis folder.

## Requirements
- Python 3.13+
- packages: pandas, numpy, matplotlib, scipy, math
