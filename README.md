# Darwin Group 45 – HIT140 Assessment 2

## Project Overview

This repository contains the HIT140 Assessment 2 group project for Darwin Group 45.

The project analyses FIFA World Cup 2026 data using Python. Each group member completed a separate analytical task involving data preparation, sampling, descriptive statistics, confidence intervals, visualisation, and statistical testing.
